Vos questions

Ce qu'on me demande sur les applications

Application web ou application sur les stores : que choisir ?

Une application web suffit dans la plupart des cas : rien à télécharger, mise à jour instantanée, un seul développement pour iPhone et Android. Les stores se justifient quand l'application doit être trouvée sur l'App Store ou Google Play, envoyer des notifications ou utiliser à fond le téléphone. On tranche ensemble au premier appel.

Mon application fonctionnera-t-elle sur iPhone et Android ?

Oui dans les deux cas : une application web s'ouvre sur tous les téléphones, et une application de store est publiée sur les deux.

Qui est propriétaire de l'application ?

Vous. Une fois le solde réglé, elle vous appartient, et les comptes sur les stores sont ouverts au nom de votre entreprise. Les frais d'inscription d'Apple et de Google sont indiqués au devis.

Combien coûte une application ?

Sur devis, selon ce qu'elle doit faire. Le premier appel et le devis sont gratuits, et vous savez exactement ce que vous payez avant de commencer.

Prêt à avoir un site qui travaille vraiment pour vous ?

Un premier échange gratuit, sans engagement, pour parler de votre activité et de ce dont vous avez besoin.
